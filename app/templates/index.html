🤖 Model Context Protocol (MCP)

Add this configuration to Claude Desktop (claude_desktop_config.json) or Cursor to let AI agents query your inbox directly.

{
  "mcpServers": {
    "life-inbox": {
      "command": "python",
      "args": ["-m", "mcp_server.server"],
      "env": {
        "DATABASE_URL": "sqlite:////Users/ishaanwadhwa/Projects/Life-Inbox/data/life_inbox.db",
        "LIFE_INBOX_API_TOKEN": "li_YOUR_TOKEN_HERE"
      }
    }
  }
}
Supports: search_inbox, add_inbox_item, list_inbox_items.

✨ Life Inbox Feature Guide

Discover what your intelligent second-brain copilot can do:

🍳 Smart Cards & Receipts Turns unstructured notes into typed recipe, book, contact cards, and tracks monthly expenses from bills.
👤 People & Entities Treemap Visual treemap scaling entities by note frequency. Click any block to view its connected notes & dossier.
🧠 Meaning-Based Semantic Search Search with completely different words (e.g. "teeth checkup" finds dentist notes) via local embeddings.
🔒 Privacy Shield & Redaction Automatically redacts phone numbers, card numbers, and PII before sending prompts to external AI.
🤖 MCP Server & Public API Connect Claude Desktop, Cursor, or custom automations directly into your personal inbox.
